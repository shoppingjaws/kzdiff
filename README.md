# kzdiff

Kustomize diff tool - Compare Kustomize build results between branches or directories.

## Overview

`kzdiff` helps you visualize the differences in Kubernetes manifests generated by Kustomize between:
- Your current changes and the base branch
- Different branches in a repository
- Different overlay environments

## Installation

### Prerequisites

- [Bun](https://bun.sh) runtime (for running the tool)
- [Git](https://git-scm.com)
- [Kustomize](https://kustomize.io)

### Method 1: Install from npm (Recommended)

```bash
# Install globally with npm
npm install -g kzdiff

# Or with bun
bun add -g kzdiff

# Or use directly with npx/bunx
npx kzdiff --help
bunx kzdiff --help
```

### Method 2: Install from source

```bash
# Clone and install
git clone https://github.com/shoppingjaws/kzdiff.git
cd kzdiff
bun install

# Create global symlink
bun link

# Add ~/.bun/bin to your PATH if not already added
echo 'export PATH="$HOME/.bun/bin:$PATH"' >> ~/.zshrc  # for zsh
source ~/.zshrc
```

### Method 3: Standalone binary

```bash
# Clone and build
git clone https://github.com/shoppingjaws/kzdiff.git
cd kzdiff
bun install

# Create standalone executable
bun run build:standalone

# Move to your PATH
sudo mv kzdiff /usr/local/bin/
```

## Usage

### Compare local changes

Compare current directory with base branch:
```bash
kzdiff
```

Compare specific directory:
```bash
kzdiff ./overlays/production
```

Compare with different base branch:
```bash
kzdiff -b develop
```

### Compare remote repository

```bash
# Compare directories in remote repository
kzdiff -r https://github.com/kubernetes-sigs/kustomize.git /examples/springboot/base

# With specific branch
kzdiff -r https://github.com/kubernetes-sigs/kustomize.git /examples/springboot/base -b kustomize/v5.5.0
```

### Options

- `-h, --help` - Show help message
- `-b, --base-branch` - Base branch to compare against (default: main)
- `-r, --remote` - Remote repository URL
- `--no-color` - Disable colored output

## Examples

### Local repository comparison

```bash
# In a Kustomize project
cd my-k8s-configs/overlays/staging
kzdiff

# Output shows differences between main branch and current changes
```

### Remote repository comparison

```bash
# Compare base vs production overlay
kzdiff -r https://github.com/kubernetes-sigs/kustomize.git /examples/springboot/base
```
