# kzdiff

A CLI tool for comparing Kustomize build results between branches.

## Overview

kzdiff helps you visualize differences in Kubernetes manifests generated by Kustomize across different Git branches. It's particularly useful for reviewing changes in Kustomize overlays during pull requests.

## Features

- Compare Kustomize builds between branches
- Colorized diff output for easy review
- Support for remote repositories
- Automatic Git state management (stashing/restoring)
- Clean error handling and informative messages

## Installation

### Prerequisites

- Git
- [Kustomize](https://kustomize.io/)

### Via npm (recommended)

```bash
npm install -g kzdiff
```

### From source

```bash
# Clone the repository
git clone https://github.com/shoppingjaws/kzdiff.git
cd kzdiff

# Install dependencies
bun install

# Build standalone binary
bun run build

# Move to your PATH
mv kzdiff /usr/local/bin/
```

## Usage

### Basic usage

Compare current directory with main branch:

```bash
kzdiff
```

### Compare with default branch

```bash
kzdiff ./examples/overlays/prod
```

### Compare with different branch

```bash
kzdiff ./examples/overlays/prod -b develop
```

### Compare with specific commit

```bash
kzdiff ./examples/overlays/prod -r 3b4d8b0121ac84d7678591d8139b6eb5f88061d6
```

### Options

- `-b, --base <branch>` - Base branch to compare against (default: main)
- `-r, --repo <url>` - Remote repository URL
- `-h, --help` - Show help message
